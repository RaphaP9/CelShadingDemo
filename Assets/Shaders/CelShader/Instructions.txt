SHADER SETTINGS

BASE SETTINGS
- Texture : Albedo (Use if you have one, otherwise leave empty)
- Color : Base Color (Most of times is better to leave as white)

LIGHTING SETTINGS
- LightingBands : Number of discretized bands (Use a low number if minimalistic look desired, high number adds a gradient look)
- LightingBandsBias : Control the bands bias towards darker bands (LightingBandsBias = 0) or more bright bands (LightingBandsBias = 1, highly recommended for low band number and Toon Shading). Intermediate values are lerped.
- MinimumMainLight : The minimum light in the lowest band of main light
- MinimumAdditionalLight : The minimum light in the lowest band of additional lights
- DarkSideMinimumLightMultiplier : There is always a dark zone where main light does not reach, this param can control the light in that zone by multiplying with MinimumMainLight
- PowerShift : Final power shift applied to all lighting (PowerShift > 1: increases intensity on high light zones, decreases intensity on low light zones. PowerShift < 1: Uniformizes all light intensities)

HIGHLIGHT
- HighlightThreshold : The threshold since where higlight appears. Disables the highligh calculations if >= 1
- HighlightIntensity : Intensity of the highlight (If using specular lighting, keep lower than SpecularIntensity to mantain a coherent visual). Disables the highlight calculations if <= 0

SPECULAR
- SpecularThreshold : The threshold since where specular lighting appears. Disables the specular calculations if >= 1
- SpecularIntensity : Intensity of the specular lighting. Disables the specular calculations if <= 0
- SpecularModulationMode: Allows specular lighting to use the attenuation or banded lighting as a multiplier. Looks more realistic in scenarios where a light comes close to the object

RIM
- RimThreshold : The threshold since where rim lighting appears. Disables the rim calculations if >= 1
- RimIntensity : Intensity of the rim lighting. Disables the rim calculations if <= 0
- RimCurveFactor : Gives rim a nail look (Nail Look: Thick on center, narrow on sides)
- RimModulationMode: Allows rim lighting to use the attenuation or banded lighting as a multiplier.

AMBIENT LIGHT
- AmbientLightIntensity : Allows shader to use ambient lighting (Can be used if an ambient based base color is desired in very low light areas)

BOOLEAN KEYWORDS (This are own created Keywords, not URP defined)
(Every boolean is self explanatory)
- UseMainLight
- UseMainLightShadows
- UseAdditionalLights
- UseAdditionalLightsShadows
